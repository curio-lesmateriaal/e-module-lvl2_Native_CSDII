**Leerdoelen**

- Je kunt een bestaande API handmatig testen met Postman of Insomnia.
- Je kunt een POST-endpoint maken dat JSON ontvangt, opslaat in MySQL (EF Core + Pomelo) en netjes een response terugstuurt.

<x-callout type="warning">

Deze opdracht bevat veel nieuwe theorie. Neem bij iedere stap de tijd om te experimenteren en goed te begrijpen wat de code doet en hoe het werkt.

</x-callout>

**Voorbereiding.** Je bouwt verder op je project uit **oefening 1**. Draait je server op `http://localhost:8080/all/` en zie je JSON? Dan zit je goed.

## Stap 1 — Installeer Postman of Insomnia

Postman en Insomnia worden in de industrie standaard gebruikt om API's te testen, te debuggen en te documenteren. Je kunt requests opslaan, zodat je een volgende keer makkelijk dezelfde API opnieuw test.

1. Download en installeer Postman of Insomnia (zoek op "Postman" of "Insomnia software").
2. Start je API zodat `GET /all` (of `/cars`) data teruggeeft.
3. In Postman/Insomnia: nieuwe request → **GET** → URL `http://localhost:8080/all` (of het pad dat jij gebruikt) → klik **Send** → bekijk het resultaat.

## Stap 2 — Maak een POST-endpoint dat JSON opslaat

Een GET-route kon je prima in de browser testen. Voor de andere HTTP-methoden, zoals **POST**, komen Postman/Insomnia echt tot hun recht. Je voegt nu een endpoint toe om nieuwe items (bijv. een `Car`) in de database te plaatsen.

Bij GET vraag je alleen om data, zonder inhoud mee te sturen:

```
GET http://localhost:8080/all
```

Bij POST stuur je ook inhoud (een request body) mee, bijvoorbeeld de data die ingevoerd moet worden:

```
POST http://localhost:8080/add
{ "brand": "Mazda", "model": "CX-5" }
```

Je gaat hiervoor code schrijven die:

1. een route herkent waarbij `context.Request.HttpMethod == "POST"` is;
2. de meegestuurde JSON deserialiseert naar een object van je modelklasse;
3. dat object in de database invoert.

**Stappenplan:**

1. Voeg een POST-route toe (bijv. `/add` of `/cars`) die:
   - de JSON-inhoud (body) leest via `context.Request.InputStream`;
   - die deserialiseert naar een object van je modelklasse;
   - het object opslaat via EF Core (`Add` + `SaveChanges`);
   - **`201 Created`** terugstuurt als antwoord, met het aangemaakte model als JSON.
2. Test de route via Postman of Insomnia: nieuwe request → **POST** → URL `http://localhost:8080/add` (of jouw pad). Voeg in de body JSON toe die past bij wat jouw API verwacht (stuur **geen** `Id` mee — die vult de database automatisch via `AUTO_INCREMENT`). Klik **Send**.
3. Krijg je `201 Created` terug met de ingevoerde data als JSON? Wat is de `Id` na het invoegen in de database?
