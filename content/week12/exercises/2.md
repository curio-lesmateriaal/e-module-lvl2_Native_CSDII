Bouwt voort op oefening 1. Nu vervang je de if-statements door **Data Annotations** op je model, plus een `[RegularExpression]`.

## Stappen

1. Voeg `using System.ComponentModel.DataAnnotations;` toe aan je modelbestand.
2. Zet attributen op de properties van je model, bijvoorbeeld:
   - `[Required]` en `[MaxLength(...)]` op een tekstveld;
   - `[Range(...)]` op een getal (bijv. de dagprijs);
   - `[RegularExpression(...)]` op minstens één veld — bijvoorbeeld een kenteken-formaat of een postcode. Voeg een `ErrorMessage` toe.
3. Vervang in je POST-route de if-statements door:

   ```csharp
   var context = new ValidationContext(nieuw);
   var results = new List<ValidationResult>();

   if (!Validator.TryValidateObject(nieuw, context, results, true))
   {
       // verzamel results[i].ErrorMessage, stuur 400 + JSON, sla niets op
   }
   ```

4. Bij geldige invoer: `Add` + `SaveChanges` + 201.

## Testen

Test dezelfde scenario's als in oefening 1, plus:

- een waarde die niet aan je `[RegularExpression]` voldoet → 400 met jouw `ErrorMessage`.
