title: GET-route op de database
type: external
description: Laat /voertuigen de echte databasegegevens teruggeven.
task: Vervang in je week 6-API de hardcoded lijst door <code>db.Voertuigen.ToList()</code>.
environment: Visual Studio 2022 — je week 6-serverproject + je week 3-database
steps:
  - Voeg je <code>Model</code>- en <code>Data</code>-map (met <code>DeSleutelContext</code>) toe aan het serverproject, of zet de server in hetzelfde project als je database.
  - Installeer de EF Core-packages als dat nog niet is gebeurd.
  - Bij route <code>/voertuigen</code> — <code>using var db = new DeSleutelContext(); var lijst = db.Voertuigen.ToList();</code>.
  - Serialiseer <code>lijst</code> en stuur het als JSON.
  - Zorg dat er minstens een paar voertuigen in de database staan (seed of via je week 4-app).
deliverables:
  - Program.cs
  - Screenshot van /voertuigen met databasegegevens
hint: Als de lijst leeg is, voeg dan eerst een paar rijen toe met je console-app van week 4.
solution: |-
  ```csharp
  if (pad == "/voertuigen")
  {
      using var db = new DeSleutelContext();
      var lijst = db.Voertuigen.ToList();
      StuurJson(context, lijst);
  }
  ```
