title: Eén voertuig uit de database
type: external
description: Combineer het id uit de URL met een database-query.
task: Laat <code>/voertuigen/{id}</code> het voertuig met dat Id uit de database teruggeven, of 404.
environment: Visual Studio 2022 — je week 7-serverproject
steps:
  - Haal het id uit <code>AbsolutePath.Split('/')</code> en zet het om met <code>int.TryParse</code>.
  - <code>using var db = new DeSleutelContext();</code>
  - <code>var v = db.Voertuigen.FirstOrDefault(x =&gt; x.Id == id);</code>
  - <code>null</code> &rarr; <code>StuurJson(context, new { fout = "Niet gevonden" }, 404);</code>
  - Anders &rarr; <code>StuurJson(context, v);</code>
deliverables:
  - Program.cs
  - Screenshot van een bestaand id én een niet-bestaand id
hint: Gebruik `Voertuig?` (nullable) voor het resultaat van FirstOrDefault.
solution: |-
  ```csharp
  string[] delen = pad.Split('/', StringSplitOptions.RemoveEmptyEntries);
  if (delen.Length == 2 && delen[0] == "voertuigen" && int.TryParse(delen[1], out int id))
  {
      using var db = new DeSleutelContext();
      var v = db.Voertuigen.FirstOrDefault(x => x.Id == id);
      if (v == null) StuurJson(context, new { fout = "Niet gevonden" }, 404);
      else StuurJson(context, v);
  }
  ```
