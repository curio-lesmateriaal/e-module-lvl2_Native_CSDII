difficulty: 4
title: Valideren met if-statements
type: external
description: Weiger een POST met ongeldige gegevens.
task: Controleer vóór het opslaan met if-statements of het kenteken en de dagprijs kloppen.
environment: Visual Studio 2022 — je week 7-serverproject
steps:
  - Maak een <code>List&lt;string&gt; fouten</code>.
  - Is <code>Kenteken</code> leeg of langer dan 8 tekens? Voeg een fout toe.
  - Is <code>Dagprijs</code> kleiner dan of gelijk aan 0? Voeg een fout toe.
  - Zijn er fouten? <code>StuurJson(context, new { fouten }, 400);</code> en <code>return;</code>
  - Anders — opslaan zoals in oefening 3.
deliverables:
  - Program.cs
  - Screenshot van een geweigerde POST (status 400 + foutenlijst)
hint: Werk met dezelfde `string.IsNullOrWhiteSpace`-check als in de theorie.
solution: |-
  ```csharp
  var fouten = new List<string>();
  if (string.IsNullOrWhiteSpace(nieuw.Kenteken)) fouten.Add("Kenteken is verplicht.");
  else if (nieuw.Kenteken.Length > 8) fouten.Add("Kenteken mag maximaal 8 tekens zijn.");
  if (nieuw.Dagprijs <= 0) fouten.Add("Dagprijs moet groter zijn dan 0.");

  if (fouten.Count > 0) { StuurJson(context, new { fouten }, 400); return; }
  ```
