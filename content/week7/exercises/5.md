title: Id uit de URL halen
type: external
description: Gebruik Segments om /voertuigen/2 af te handelen.
task: Voeg een route toe die bij <code>/voertuigen/{id}</code> één voertuig teruggeeft.
environment: Visual Studio 2022 — je project Week7.Server
steps:
  - Splits <code>context.Request.Url.Segments</code> of gebruik <code>AbsolutePath.Split('/')</code>.
  - Herken het patroon — segment 1 is "voertuigen", segment 2 is het id.
  - Zet het id om met <code>int.TryParse</code>.
  - Zoek het voertuig met <code>FirstOrDefault(v =&gt; v.Id == id)</code>; niet gevonden &rarr; status 404.
  - Gevonden &rarr; serialiseer dat ene object en stuur het.
deliverables:
  - Program.cs
  - Screenshot van /voertuigen/2 én van een niet-bestaand id
hint: "`AbsolutePath` van `/voertuigen/2` is `/voertuigen/2`; `Split('/')` geeft dan `[\"\", \"voertuigen\", \"2\"]`."
solution: |-
  ```csharp
  string[] delen = context.Request.Url.AbsolutePath.Split('/', StringSplitOptions.RemoveEmptyEntries);
  if (delen.Length == 2 && delen[0] == "voertuigen" && int.TryParse(delen[1], out int id))
  {
      var v = voertuigen.FirstOrDefault(x => x.Id == id);
      if (v == null) { context.Response.StatusCode = 404; /* stuur foutmelding */ }
      else { /* serialiseer v en stuur */ }
  }
  ```
