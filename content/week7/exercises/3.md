title: POST — een voertuig toevoegen
type: external
description: Lees een POST-body uit, deserialiseer en sla op.
task: Voeg een route toe die op <code>POST /voertuigen</code> een nieuw voertuig uit de JSON-body opslaat in de database.
environment: Visual Studio 2022 — je week 7-serverproject + Thunder Client of Postman
steps:
  - Controleer <code>context.Request.HttpMethod == "POST"</code> en het pad.
  - Lees de body — <code>using var reader = new StreamReader(context.Request.InputStream); string body = reader.ReadToEnd();</code>
  - Deserialiseer met <code>PropertyNameCaseInsensitive = true</code> naar een <code>Voertuig</code>.
  - <code>db.Voertuigen.Add(nieuw); db.SaveChanges();</code>
  - Stuur het opgeslagen voertuig terug met status 201.
  - Test met Thunder Client — methode POST, body = JSON met kenteken/merk/type/dagprijs.
deliverables:
  - Program.cs
  - Screenshot van de POST in Thunder Client én de nieuwe rij in de database
hint: Een browser kan geen POST met een body versturen — gebruik Thunder Client (VS Code-extensie) of Postman.
solution: |-
  ```csharp
  if (context.Request.HttpMethod == "POST" && pad == "/voertuigen")
  {
      using var reader = new StreamReader(context.Request.InputStream);
      string body = reader.ReadToEnd();
      var options = new JsonSerializerOptions { PropertyNameCaseInsensitive = true };
      var nieuw = JsonSerializer.Deserialize<Voertuig>(body, options);

      using var db = new DeSleutelContext();
      db.Voertuigen.Add(nieuw);
      db.SaveChanges();
      StuurJson(context, nieuw, 201);
  }
  ```
