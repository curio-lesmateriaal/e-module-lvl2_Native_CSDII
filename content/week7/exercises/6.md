title: Response-helper
type: external
description: Haal de herhaling uit je routes met één methode.
task: Schrijf een methode <code>StuurJson(HttpListenerContext context, object data, int status = 200)</code> en gebruik die overal.
environment: Visual Studio 2022 — je project Week7.Server
steps:
  - Maak de methode — serialiseer <code>data</code>, zet <code>ContentType</code>, <code>StatusCode</code> en <code>ContentLength64</code>, schrijf en sluit de stream.
  - Vervang in al je routes de losse verzendcode door een aanroep van <code>StuurJson(...)</code>.
  - Maak voor onbekende routes <code>StuurJson(context, new { fout = "Onbekende route" }, 404);</code>.
  - Test alle routes opnieuw.
deliverables:
  - Program.cs met de helper
  - Korte uitleg (2-3 zinnen) — waarom is dit prettiger dan de code herhalen?
hint: Een anoniem object `new { fout = "..." }` is genoeg voor een simpele JSON-foutmelding.
solution: |-
  ```csharp
  static void StuurJson(HttpListenerContext context, object data, int status = 200)
  {
      string json = JsonSerializer.Serialize(data);
      byte[] buffer = Encoding.UTF8.GetBytes(json);
      context.Response.StatusCode = status;
      context.Response.ContentType = "application/json";
      context.Response.ContentLength64 = buffer.Length;
      context.Response.OutputStream.Write(buffer, 0, buffer.Length);
      context.Response.OutputStream.Close();
  }
  ```
