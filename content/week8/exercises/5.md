id: 5
difficulty: 5
title: Valideren met Data Annotations
type: external
description: Vervang de if-statements door attributen op het model.
task: Zet <code>[Required]</code>, <code>[MaxLength]</code>, <code>[Range]</code> en een <code>[RegularExpression]</code> op <code>Voertuig</code> en valideer met <code>Validator.TryValidateObject</code>.
environment: Visual Studio 2022 — je week 8-serverproject
steps:
  - Voeg <code>using System.ComponentModel.DataAnnotations;</code> toe.
  - 'Zet op <code>Kenteken</code>: <code>[Required]</code> en een <code>[RegularExpression(...)]</code> met een eigen ErrorMessage.'
  - 'Zet op <code>Merk</code>: <code>[Required]</code> en <code>[MaxLength(50)]</code>; zet op <code>Dagprijs</code> een <code>[Range(1, 1000)]</code>.'
  - 'Bij de POST: maak een <code>ValidationContext</code> en een <code>List&lt;ValidationResult&gt;</code> en roep <code>Validator.TryValidateObject(nieuw, ctx, results, true)</code> aan.'
  - 'Bij <code>false</code>: stuur de <code>ErrorMessage</code>s als JSON met status 400.'
deliverables:
  - Voertuig.cs met de attributen
  - Program.cs met de validatie
  - Screenshot van een geweigerde POST met de foutmeldingen uit de attributen
hint: Vergeet de vierde parameter `true` van TryValidateObject niet — anders worden niet alle attributen gecontroleerd.
solution: |-
  ```csharp
  var ctx = new ValidationContext(nieuw);
  var results = new List<ValidationResult>();
  if (!Validator.TryValidateObject(nieuw, ctx, results, true))
  {
      var fouten = results.Select(r => r.ErrorMessage).ToList();
      StuurJson(context, new { fouten }, 400);
      return;
  }
  ```
