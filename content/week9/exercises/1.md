title: Hallo, webserver
type: external
description: Start een HttpListener die op elk verzoek "Hallo" terugstuurt.
task: Bouw een console-app die luistert op poort 8080 en op elk verzoek de tekst <code>Hallo vanaf mijn C#-server</code> terugstuurt.
environment: Visual Studio 2022 — nieuw Console App-project Week9.Server
steps:
  - Voeg <code>using System.Net;</code> en <code>using System.Text;</code> toe.
  - Maak een <code>HttpListener</code>, voeg de prefix <code>http://localhost:8080/</code> toe en start hem.
  - Doe <code>var context = listener.GetContext();</code> en pak de <code>Response</code>.
  - Zet een tekst om naar bytes, zet <code>ContentLength64</code>, schrijf naar <code>OutputStream</code> en sluit die.
  - Open <code>http://localhost:8080/</code> in je browser.
deliverables:
  - Program.cs
  - Screenshot van de browser met de tekst
hint: "Krijg je 'Access denied' bij Start()? Draai Visual Studio als administrator, of gebruik poort 8080 (die mag meestal wel zonder rechten)."
solution: |-
  ```csharp
  using System.Net;
  using System.Text;

  var listener = new HttpListener();
  listener.Prefixes.Add("http://localhost:8080/");
  listener.Start();
  Console.WriteLine("Server draait op http://localhost:8080/");

  var context = listener.GetContext();
  var response = context.Response;

  byte[] buffer = Encoding.UTF8.GetBytes("Hallo vanaf mijn C#-server");
  response.ContentLength64 = buffer.Length;
  response.OutputStream.Write(buffer, 0, buffer.Length);
  response.OutputStream.Close();
  ```
