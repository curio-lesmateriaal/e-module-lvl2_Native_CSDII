difficulty: 3
title: Blijven draaien
type: external
description: Zet een lus rond GetContext zodat de server meerdere verzoeken afhandelt.
task: Pas oefening 1 aan zodat de server niet stopt na één verzoek.
environment: Visual Studio 2022 — je project Week7.Server
steps:
  - Zet <code>GetContext()</code> en het beantwoorden in een <code>while (true)</code>-lus.
  - Print bij elk verzoek in de console het tijdstip en de opgevraagde URL (<code>context.Request.Url</code>).
  - Ververs je browser een paar keer en kijk naar de console.
deliverables:
  - Program.cs
  - Screenshot van de console met meerdere verzoeken
hint: Alles wat per verzoek moet gebeuren (context ophalen, antwoord schrijven, stream sluiten) hoort ín de lus.
solution: |-
  ```csharp
  while (true)
  {
      var context = listener.GetContext();
      Console.WriteLine($"{DateTime.Now:T}  {context.Request.Url.AbsolutePath}");

      byte[] buffer = Encoding.UTF8.GetBytes("Hallo");
      context.Response.ContentLength64 = buffer.Length;
      context.Response.OutputStream.Write(buffer, 0, buffer.Length);
      context.Response.OutputStream.Close();
  }
  ```
