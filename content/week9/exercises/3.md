difficulty: 4
title: Routes met AbsolutePath
type: external
description: Geef verschillende antwoorden op /hello en /goodbye.
task: Laat de server op <code>/hello</code> een groet tonen en op <code>/goodbye</code> een afscheid; andere routes krijgen "Onbekende route".
environment: Visual Studio 2022 — je project Week7.Server
steps:
  - Haal in de lus <code>context.Request.Url.AbsolutePath</code> op.
  - Gebruik een <code>if / else if / else</code> (of <code>switch</code>) om het antwoord te bepalen.
  - Bij een onbekende route — zet <code>context.Response.StatusCode = 404;</code> en stuur een korte tekst.
deliverables:
  - Program.cs
  - Screenshot van /hello, /goodbye én een onbekende route
hint: Bepaal eerst de string `antwoord`, en doe de bytes-omzetting + verzenden daarna één keer onderaan.
solution: |-
  ```csharp
  string pad = context.Request.Url.AbsolutePath;
  string antwoord = pad switch
  {
      "/hello"   => "Hallo!",
      "/goodbye" => "Tot ziens!",
      _          => "Onbekende route"
  };
  if (antwoord == "Onbekende route") context.Response.StatusCode = 404;
  ```
