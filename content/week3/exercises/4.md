difficulty: 4
title: Eerste migratie
type: external
description: Maak en draai je eerste migratie.
task: Maak met de Package Manager Console een migratie en voer die uit op je database.
environment: Visual Studio 2022 — Package Manager Console
steps:
  - Open Tools &rarr; NuGet Package Manager &rarr; Package Manager Console.
  - Typ <code>Add-Migration InitieleDatabase</code> en druk op Enter.
  - Bekijk het gegenereerde bestand in de map <code>Migrations</code> — herken je de <code>Up</code>- en <code>Down</code>-methode?
  - Typ <code>Update-Database</code> en druk op Enter.
  - Controleer in je database-tool dat de tabel <code>ToDos</code> bestaat met een kolom per property.
deliverables:
  - Screenshot van de Package Manager Console met 'Done.'
  - Screenshot van de tabel ToDos in je database
hint: "Fout 'No DbContext was found'? Zorg dat je project bouwt en dat de Default project in de console op Week3.ToDo staat."
solution: |-
  Na `Update-Database` bestaat de tabel `ToDos` met kolommen `Id`, `Title`, `Description`, `Deadline`, `IsDone` en een tabel `__EFMigrationsHistory`.
