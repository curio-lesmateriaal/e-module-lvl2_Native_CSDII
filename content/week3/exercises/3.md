title: De DbContext
type: external
description: Schrijf de dataclass met OnConfiguring en een DbSet.
task: Maak een map <code>Data</code> met een class <code>ToDoContext</code> die erft van <code>DbContext</code>, met een correcte <code>OnConfiguring</code> en een <code>DbSet&lt;ToDo&gt;</code>.
environment: Visual Studio 2022 — je project Week3.ToDo
steps:
  - Maak een MySQL-database aan, bijv. <code>week3_todo</code>.
  - 'Voeg in de map <code>Data</code> de class <code>ToDoContext : DbContext</code> toe.'
  - Neem de <code>OnConfiguring</code>-methode uit de theorie over en pas server, user, password en database aan naar jouw situatie.
  - Voeg toe — <code>public DbSet&lt;ToDo&gt; ToDos { get; set; }</code>.
  - Bouw het project; los eventuele <code>using</code>-fouten op (<code>using Microsoft.EntityFrameworkCore;</code>).
deliverables:
  - Data/ToDoContext.cs
hint: De juiste ServerVersion hangt af van je database. Bij MariaDB via Laragon is dat iets als `ServerVersion.Parse("10.4.17-mariadb")`.
solution: |-
  ```csharp
  using Microsoft.EntityFrameworkCore;
  using Week3.ToDo.Model;

  namespace Week3.ToDo.Data;

  public class ToDoContext : DbContext
  {
      public DbSet<ToDo> ToDos { get; set; }

      protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
      {
          if (!optionsBuilder.IsConfigured)
          {
              optionsBuilder.UseMySql(
                  "server=localhost;port=3306;user=c_sharp;password=c_sharp;database=week3_todo",
                  ServerVersion.Parse("10.4.17-mariadb"));
          }
      }
  }
  ```
