title: Model ToDo
type: external
description: Schrijf de model-class ToDo met properties.
task: Maak een map <code>Model</code> en daarin een class <code>ToDo</code> met de properties Id, Title, Description, Deadline en IsDone.
environment: Visual Studio 2022 — je project Week3.ToDo
steps:
  - Rechtsklik het project &rarr; Add &rarr; New Folder &rarr; <code>Model</code>.
  - Voeg in <code>Model</code> een class <code>ToDo</code> toe.
  - Geef de class de properties uit de theorie (let op — <em>properties</em>, dus met <code>{ get; set; }</code>).
  - Zorg dat <code>Id</code> een <code>int</code> is — dat wordt straks je primaire sleutel.
deliverables:
  - Model/ToDo.cs
hint: Kopieer de ToDo-class uit de theorie en controleer dat er nergens een kale field-declaratie (`int Id;`) staat.
solution: |-
  ```csharp
  namespace Week3.ToDo.Model;

  public class ToDo
  {
      public int Id { get; set; }
      public string Title { get; set; }
      public string Description { get; set; }
      public DateTime Deadline { get; set; }
      public bool IsDone { get; set; }
  }
  ```
