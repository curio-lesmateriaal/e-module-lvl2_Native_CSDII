In deze opdracht bouw je een eenvoudige **CRUD**-applicatie (Create, Read, Update, Delete). Gebruik als startpunt het project **`SimpleCrudEmpty.zip`** — dat staat op **Itslearning**. In het project staan `// TODO`-opmerkingen die je kunt volgen; anders volg je de stappen hieronder.

In de stappen gebruiken we `Pokemon` als voorbeeldklasse. Kies gerust je eigen class — pas de namen dan overal consequent aan.

## Stappen

1. Pak `SimpleCrudEmpty.zip` uit en open het project `SimpleCrud`.
2. Maak in de `Model`-map een nieuwe class (bijv. `Pokemon`).
3. Geef de class een property `Id` en minstens één andere property (bijv. `Name`):

   ```csharp
   public int Id { get; set; }
   public string Name { get; set; }
   ```

4. Voeg een constructor toe met een parameter voor alle properties **behalve** `Id`.
5. Pas in `SimpleCrudDataContext.cs` de gegevens van je database aan (`user`, `password` en `database`).
6. Voeg in `SimpleCrudDataContext.cs` een `DbSet` toe voor jouw class:

   ```csharp
   public DbSet<Pokemon> Pokemons { get; set; }
   ```

7. Maak een migratie. Typ in de Package Manager Console:

   ```powershell
   Add-Migration "Mijn migratienaam"
   ```

8. Werk je database bij. Typ in de Package Manager Console:

   ```powershell
   Update-Database
   ```

9. Controleer of je database en tabel zijn aangemaakt. Voeg vervolgens in phpMyAdmin (of een ander databaseprogramma) **één** object toe aan je tabel.
10. Pas in `SimpleCrudApp.cs` de methode `ShowAll` aan:
    - Maak een `List` met alle gegevens uit de database:

      ```csharp
      List<Pokemon> pokemons = dataContext.Pokemons.ToList();
      ```

    - Herschrijf het `foreach`-statement zodat het naar jouw list kijkt; pas `Object`, `obj` en `objects` aan naar de juiste types en namen.
11. Controleer of je app werkt: hij zou moeten compileren en het object moeten weergeven dat je zojuist in de database hebt gezet.
12. Schrijf de methode `AddNew`:
    - Vraag de gebruiker om de gegevens van het nieuwe object;
    - Maak een nieuw object aan met die gegevens;
    - Voeg het object toe aan de `dataContext`;
    - Sla de `dataContext` op (`SaveChanges`).

    Controleer of je nu een nieuw object kunt toevoegen.
13. Pas de methode `SelectObject` aan:
    - Pas het returntype aan naar jouw class (bijv. `Pokemon`);
    - Pas de methodenaam aan (bijv. `SelectPokemon`);
    - Vervang overal `object` door jouw class of classnaam (bijv. `selectedObject` → `selectedPokemon`);
    - Zorg dat je het juiste object vindt:

      ```csharp
      selectedPokemon = dataContext.Pokemons.Find(selectedPokemonId);
      ```

14. Schrijf nu met de opgedane kennis zelf de methoden `Update` en `Delete`. Test tussendoor steeds je app!

<x-callout type="tip">

Als je een methode hernoemt of het returntype verandert, pas dan in één keer álle bijbehorende namen aan (methodenaam, variabelen, aanroepen). Als je app niet meer compileert, wijst de foutmelding je meestal precies naar de plek die je nog moet aanpassen.

</x-callout>
