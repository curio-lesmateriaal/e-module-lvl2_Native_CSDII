**Leerdoelen**

- Je kunt een API consumeren in een client-applicatie.
- Je begrijpt het verschil tussen een API die data serveert (server) en een app die data gebruikt (client).
- Je kunt in WinUI 3 een `ListView` gebruiken om een lijst uit de API weer te geven.
- Je kunt met `HttpClient` GET- en POST-requests uitvoeren.

In deze opdracht bouw je een **grafische** client-applicatie die jouw eigen API gebruikt. In oefening 1 en 2 deed je dat vanuit een console-app; nu maak je er een WinUI 3-app van met twee schermen:

- **OverviewPage** — haalt met een GET-request de data uit de API en toont die in een `ListView`.
- **CreatePage** — stuurt met een POST-request nieuwe data naar de API, via invoervelden die de gebruiker zelf invult.

<x-callout type="tip">

De client-app heeft **geen** database nodig: je installeert dus **niet** Pomelo of Entity Framework. De database zit al aan de API-kant. Jouw WinUI-app praat via `HttpClient` met de API en haalt daar data op of voegt data toe.

In WinUI 3 kun je `ListView.ItemsSource` direct vullen met een `List` (bijvoorbeeld `List<Car>`). Deserialiseer je de JSON van de API naar een lijst, dan kun je die meteen tonen in de UI.

</x-callout>

## Stappenplan

1. Maak een nieuw WinUI 3-project (*Blank App, Packaged (WinUI 3 in Desktop)*), bijv. `ClientApp`. Maak de modelklasse aan die je nodig hebt om te deserialiseren — waarschijnlijk precies dezelfde als in je API-project (bijv. `Car`).
2. Maak in `MainWindow` een `Frame`-element en voeg twee pagina's toe:
   - `OverviewPage` met een `ListView` waarin alle items (bijv. `Car`-objecten) getoond worden;
   - `CreatePage` met invoervelden voor de eigenschappen van een nieuw item (bijv. `Brand` en `Model`).
3. Gebruik `Frame.Navigate(...)` om bij het opstarten naar `OverviewPage` te navigeren. (Navigeren tussen Pages met een `Frame` en gegevens meesturen: zie de WinUI-hand-out over Pages/Navigate op Itslearning.)

**In `OverviewPage`:**

4. Een `HttpClient` die met **GET** alle items ophaalt.
5. Deserialiseer de JSON naar een `List<...>` (met een klasse die je data helpt deserialiseren).
6. Zet die `List<...>` in de `ItemsSource` van de `ListView`.
7. Een knop die de gebruiker naar `CreatePage` navigeert.

Test je applicatie regelmatig tussendoor.

**In `CreatePage`:**

8. Invoervelden waarmee de gebruiker de waarden voor de eigenschappen van een object kan kiezen.
9. Een knop om de keuzes te bevestigen en het object aan te maken.
10. Bij een klik op die knop: stuur een **POST**-request naar je API met de gemaakte keuzes als JSON (zoals in oefening 2).
11. Toon nette foutmeldingen wanneer die zich voordoen (bijvoorbeeld als niet alle eigenschappen zijn ingevuld).

Daarna heb je een grafische client-applicatie die met je eigen API communiceert. (In week 11 laat je diezelfde API zijn data uit een echte database halen.)
