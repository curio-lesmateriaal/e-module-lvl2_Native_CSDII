Je gebruikt je **server uit week 9** (de `HttpListener`-console-app met de route `http://localhost:8080/all`). Nu schrijf je een **tweede** console-app die die server uitleest.

## Stappen

1. Maak een nieuw Console App-project `Week10.Client`. Je hebt hier **geen** database en **geen** EF Core / Pomelo nodig.
2. Maak dezelfde modelklasse als in je server-project (bijv. `Car` met `Id`, `Brand`, `Model`).
3. Maak `Main` asynchroon (`static async Task Main`).
4. Doe met `HttpClient` een `GetAsync` naar `http://localhost:8080/all` en lees het antwoord met `ReadAsStringAsync`.
5. Deserialiseer de JSON naar een `List<Car>` (met `PropertyNameCaseInsensitive = true`).
6. Print elke auto met een `foreach`.

## Testen

1. Start eerst je **server** uit week 9 (die blijft draaien).
2. Start daarnaast je **client**. Zie je dezelfde lijst als wanneer je `http://localhost:8080/all` in de browser opent?
