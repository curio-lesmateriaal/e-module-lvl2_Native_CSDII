difficulty: 5
title: Standaardwaarde via static
type: external
description: Gebruik een static field als instelbare standaardwaarde.
task: Geef <code>Voertuig</code> een static <code>StandaardDagprijs</code> die gebruikt wordt als er bij het aanmaken geen prijs wordt opgegeven.
environment: Visual Studio 2022 — je project van week 1 (Autoverhuur De Sleutel)
steps:
  - Voeg <code>public static decimal StandaardDagprijs = 45m;</code> toe aan <code>Voertuig</code>.
  - Maak een tweede constructor die alleen kenteken, merk en type krijgt en de dagprijs op <code>StandaardDagprijs</code> zet.
  - Wijzig in <code>Program.cs</code> vóór het aanmaken van voertuigen <code>Voertuig.StandaardDagprijs = 50m;</code> en maak daarna een voertuig zonder prijs aan.
  - Controleer dat dat voertuig 50 als dagprijs heeft.
deliverables:
  - Bijgewerkte Voertuig.cs
  - Screenshot van de output
hint: "Een tweede constructor mag de eerste aanroepen met `: this(kenteken, merk, type, StandaardDagprijs)`."
solution: |-
  ```csharp
  public static decimal StandaardDagprijs = 45m;

  public Voertuig(string kenteken, string merk, string type)
      : this(kenteken, merk, type, StandaardDagprijs)
  {
  }
  ```
