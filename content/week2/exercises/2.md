In deze opdracht werk je aan een kleine console-applicatie: een bankrekening-app (`BankApp`). Het startproject staat op **Itslearning** — download het, pak het uit en open het.

De code bevat, net als bij de vorige opdracht, opzettelijk foutieve of ontbrekende access modifiers (`public`, `private`, `static`). Daarnaast staan een aantal methode- en veldnamen nog in het Nederlands.

## Opdracht

1. Analyseer de code en voeg waar nodig de juiste access modifiers toe;
2. Zorg dat de applicatie correct werkt en voldoet aan de conventies;
3. Geef elke methode en elk veld een logische modifier op basis van zijn functie en bereik (toegankelijkheid);
4. Vertaal de Nederlandse namen naar correcte Engelse benamingen, bijvoorbeeld:

   | Nederlands | Engels |
   |---|---|
   | `eigenaar` | `owner` |
   | `saldo` | `balance` |
   | `ZetGegevens` | `SetOwner` |
   | `Storten` | `Deposit` |
   | `Opnemen` | `Withdraw` |
   | `ToonInfo` | `ShowInfo` |
   | `GeefSaldo` | `GetBalance` |

Let op: als je een methode hernoemt, moet je ook de aanroep ervan in `Program.cs` aanpassen.

<x-callout type="tip">

Kijk per methode wie hem aanroept. Wordt een methode alleen vanuit de klasse zelf gebruikt (zoals de methode die het saldo teruggeeft aan de eigen "toon informatie"-methode), dan mag hij `private` blijven. Wordt een methode vanuit `Program.cs` aangeroepen, dan moet hij `public` zijn.

</x-callout>

## Wat lever je in

- Een zip-bestand met je (gecorrigeerde) project;
- **1** duidelijke screenshot van de werkende console-uitvoer van `BankApp`. Breng in de screenshot een stuk code **plus** het bijbehorende resultaat in beeld, zodat te zien is dat jouw access modifiers correct zijn toegepast.

Inleveren via **Itslearning**, onder de map "Module: Native (C#)".
