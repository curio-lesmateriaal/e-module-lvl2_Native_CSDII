title: Saldo beschermen
type: external
description: Maak het saldo alleen aanpasbaar via methoden.
task: Bouw <code>Rekening</code> zo dat het saldo van buitenaf gelezen mag worden, maar alleen gewijzigd via <code>Stort</code> en <code>Neemop</code>.
environment: Visual Studio 2022 — je project Week2.Oefeningen
steps:
  - Maak van <code>saldo</code> een property <code>Saldo</code> met <code>{ get; private set; }</code>.
  - <code>Stort(decimal bedrag)</code> telt het bedrag bij het saldo op (weiger negatieve bedragen).
  - <code>Neemop(decimal bedrag)</code> haalt het bedrag eraf, maar alleen als er genoeg saldo is.
  - Test vanuit <code>Program.cs</code> — storten, opnemen, te veel opnemen, negatief storten.
deliverables:
  - Rekening.cs
  - Screenshot waarin een geweigerde opname te zien is
hint: "`{ get; private set; }` betekent: iedereen mag lezen, alleen de class zelf mag schrijven."
solution: |-
  ```csharp
  public class Rekening
  {
      public decimal Saldo { get; private set; }

      public void Stort(decimal bedrag)
      {
          if (bedrag <= 0) { Console.WriteLine("Bedrag moet positief zijn."); return; }
          Saldo += bedrag;
      }

      public void Neemop(decimal bedrag)
      {
          if (bedrag > Saldo) { Console.WriteLine("Onvoldoende saldo."); return; }
          Saldo -= bedrag;
      }
  }
  ```
