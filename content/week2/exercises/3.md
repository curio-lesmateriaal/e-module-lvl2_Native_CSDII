difficulty: 4
title: Static teller
type: external
description: Houd met een static field bij hoeveel objecten er zijn aangemaakt.
task: Geef <code>Rekening</code> een static teller <code>AantalRekeningen</code> die met 1 omhoog gaat bij elke nieuwe rekening, plus een uniek <code>Rekeningnummer</code>.
environment: Visual Studio 2022 — je project Week2.Oefeningen
steps:
  - Voeg <code>public static int AantalRekeningen;</code> toe.
  - Voeg een property <code>Rekeningnummer</code> toe met een private set.
  - Verhoog in de constructor <code>AantalRekeningen</code> en gebruik de nieuwe waarde als rekeningnummer.
  - Maak in <code>Program.cs</code> drie rekeningen en print na elke aanmaak <code>Rekening.AantalRekeningen</code>.
deliverables:
  - Bijgewerkte Rekening.cs
  - Screenshot met de oplopende teller (1, 2, 3)
hint: Een static field bestaat één keer voor de héle class, niet per object — daarom is het geschikt als teller.
solution: |-
  ```csharp
  public static int AantalRekeningen;
  public int Rekeningnummer { get; private set; }

  public Rekening()
  {
      AantalRekeningen++;
      Rekeningnummer = AantalRekeningen;
  }
  ```
