In deze opdracht werk je aan twee kleine console-applicaties: een gebruikersapp (`UserApp`) en een rekenmachine-app (`CalculatorApp`). Het startproject staat op **Itslearning** — download het, pak het uit en open het.

Beide applicaties bevatten **opzettelijk** foutieve of ontbrekende access modifiers (`public`, `private`, `static`).

## Opdracht

1. Analyseer de code en voeg waar nodig de juiste access modifiers toe;
2. Zorg dat de applicatie correct werkt en voldoet aan de conventies;
3. Geef elke methode en elk veld een logische modifier op basis van zijn functie en bereik (toegankelijkheid);
4. Zet de code om naar correcte Engelse benamingen, voor zover dat nog niet is gebeurd.

<x-callout type="tip">

Kijk per veld en per methode: wordt dit alleen binnen de klasse zelf gebruikt, of ook van buitenaf (bijvoorbeeld vanuit `Program.cs`)? Alleen intern → `private`. Van buitenaf nodig → `public`. Hoort iets bij de klasse als geheel in plaats van bij één object → `static`.

</x-callout>

## Wat lever je in

- Een zip-bestand met je project(en);
- **2** duidelijke screenshots van de werkende console-uitvoer van beide applicaties (`UserApp` en `CalculatorApp`). Zorg dat je bij de screenshots een stuk code **plus** het bijbehorende resultaat in beeld brengt, zodat te zien is dat jouw access modifiers correct zijn toegepast.

Inleveren via **Itslearning**, onder de map "Module: Native (C#)".
