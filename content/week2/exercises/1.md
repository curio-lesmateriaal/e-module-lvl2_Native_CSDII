Maak een nieuw console-project `Week2.Oefeningen` en zet er een class `Rekening` in met deze code:

```csharp
public class Rekening
{
    int saldo;

    void Stort(decimal bedrag) { }
}
```

Probeer nu in `Program.cs` het volgende:

```csharp
var r = new Rekening();
r.saldo = 100;
r.Stort(50);
```

**Vragen (noteer je antwoorden):**

1. Welke twee foutmeldingen krijg je?
2. Wat is de standaard-toegankelijkheid van een field of methode als je *niets* opgeeft?
3. Welke modifier moet je toevoegen om de code wél te laten werken?
