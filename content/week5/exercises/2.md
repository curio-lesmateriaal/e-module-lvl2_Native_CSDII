Bouwt voort op oefening 1. Een `TextBox` is geen nette manier om een lijst te tonen — we gaan over op een `ListView`.

## Opdracht 1 — De ListView in XAML

1. Verwijder in `MainWindow.xaml` de `TextBox` (en de `StackPanel` eromheen als je die niet meer gebruikt).
2. Voeg bovenin `<Window ...>` de namespace van je model toe: `xmlns:local="using:DevCitySim.Data"`.
3. Voeg een `ListView` toe met `x:Name="citizenListView"` en een `ItemTemplate` / `DataTemplate` met `x:DataType="local:Citizen"`. Toon in het template minstens de `Name`.

## Opdracht 2 — De ListView vullen

1. Verwijder in `MainWindow.xaml.cs` alle code die met de oude `TextBox` te maken had.
2. Vul in de constructor (na het opbouwen van de database) de `ListView`:

   ```csharp
   using (var db = new AppDbContext())
   {
       citizenListView.ItemsSource = db.Citizens.ToList();
   }
   ```

3. Start de app — zie je je bewoners in de lijst?

## Opdracht 3 — Het item mooier maken

Breid het `DataTemplate` uit met een tweede `TextBlock` voor de `Job` (bijvoorbeeld met een lagere `Opacity`). Test opnieuw.
