difficulty: 6
title: Kenteken opzoeken
type: external
description: Bouw een mini-client die op zoekterm gegevens ophaalt.
task: Vraag de gebruiker om een id/kenteken, bouw daarmee de API-URL op en toon het resultaat.
environment: Visual Studio 2022 — je project Week5.Api
steps:
  - Vraag met <code>Console.ReadLine()</code> een waarde (bijv. een Pokémon-naam of een jsonplaceholder-id).
  - Bouw de URL op met string-interpolatie — <code>$"https://pokeapi.co/api/v2/pokemon/{invoer}"</code>.
  - Controleer <code>response.IsSuccessStatusCode</code> voordat je gaat deserialiseren.
  - "Bij succes: deserialiseer en toon de velden. Bij mislukking: nette melding."
deliverables:
  - Program.cs
  - Screenshot van een geslaagde én een mislukte zoekopdracht
hint: "`response.IsSuccessStatusCode` is false bij bijvoorbeeld een 404 — vang dat af voordat je Deserialize aanroept."
solution: |-
  ```csharp
  Console.Write("Naam: ");
  string invoer = Console.ReadLine();
  var response = await client.GetAsync($"https://pokeapi.co/api/v2/pokemon/{invoer}");
  if (!response.IsSuccessStatusCode)
  {
      Console.WriteLine($"Niets gevonden voor '{invoer}'.");
      return;
  }
  var content = await response.Content.ReadAsStringAsync();
  var pokemon = JsonSerializer.Deserialize<Pokemon>(content, options);
  Console.WriteLine($"{pokemon.Name} weegt {pokemon.Weight}");
  ```
