title: Een taak afvinken (Update)
type: external
description: Haal één taak op, zet IsDone op true en sla op.
task: Vraag de gebruiker om de titel van een taak, haal die op en markeer hem als voldaan.
environment: Visual Studio 2022 — je project Week3.ToDo
steps:
  - Vraag een titel met <code>Console.ReadLine()</code>.
  - Haal de taak op met <code>FirstOrDefault(t =&gt; t.Title == titel)</code>.
  - Is de taak <code>null</code>? Print "niet gevonden" en stop.
  - Anders — <code>taak.IsDone = true;</code> en <code>db.SaveChanges();</code>.
  - Toon daarna alle taken om te controleren.
deliverables:
  - Program.cs
  - Screenshot waarin een taak van 'open' naar 'voldaan' gaat
hint: Je hoeft geen Update-methode aan te roepen — een property aanpassen op een opgehaald object is genoeg, dankzij Change Tracking.
solution: |-
  ```csharp
  var taak = db.ToDos.FirstOrDefault(t => t.Title == titel);
  if (taak == null)
  {
      Console.WriteLine("Taak niet gevonden.");
  }
  else
  {
      taak.IsDone = true;
      db.SaveChanges();
      Console.WriteLine("Afgevinkt!");
  }
  ```
