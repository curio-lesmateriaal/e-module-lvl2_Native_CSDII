title: Een taak verwijderen (Delete)
type: external
description: Verwijder een taak op basis van zijn Id.
task: Vraag een Id, haal de taak op en verwijder hem met Remove + SaveChanges.
environment: Visual Studio 2022 — je project Week3.ToDo
steps:
  - Print eerst alle taken mét hun <code>Id</code>.
  - Vraag een Id en zet het om met <code>int.TryParse</code>.
  - Haal de taak op met <code>FirstOrDefault(t =&gt; t.Id == id)</code> en check op <code>null</code>.
  - <code>db.ToDos.Remove(taak);</code> en <code>db.SaveChanges();</code>.
  - Toon de lijst opnieuw.
deliverables:
  - Program.cs
  - Screenshot vóór en ná het verwijderen
hint: "`int.TryParse(Console.ReadLine(), out int id)` geeft false bij ongeldige invoer — vang dat netjes af."
solution: |-
  ```csharp
  if (int.TryParse(Console.ReadLine(), out int id))
  {
      var taak = db.ToDos.FirstOrDefault(t => t.Id == id);
      if (taak == null) Console.WriteLine("Geen taak met dat Id.");
      else { db.ToDos.Remove(taak); db.SaveChanges(); Console.WriteLine("Verwijderd."); }
  }
  ```
