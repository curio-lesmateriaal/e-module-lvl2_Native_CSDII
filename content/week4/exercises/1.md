In deze opdracht maak je een C#-app, verbind je met de database, maak je een eigen model en sla je gegevens op. Bedenk zelf een onderwerp voor je app (bijvoorbeeld **boeken**, **games** of **Pokémon**), maak daar een model (class) van, verbind met je database via EF Core en sla ten minste één item op.

In de stappen gebruiken we `Pokemon` als voorbeeld. Kies je een ander onderwerp, pas de namen dan overal consequent aan.

## Stappen

1. Start een nieuwe **Console App**.
2. Verbind je app met je database via EF Core. Volg hiervoor de theorie van **week 3**: installeer de packages (§3.3), maak je `DbContext` met `OnConfiguring` (§3.5).
3. Maak in de map `Model` een nieuwe class met een passende naam (bijv. `Pokemon`).
4. Geef de class een property `Id` en daarnaast een property voor elk gegeven dat je wilt bijhouden. Voor Pokémon bijvoorbeeld:

   ```csharp
   public int Id { get; set; }
   public string Name { get; set; }
   public string Ability { get; set; }
   ```

5. Voeg in je `DbContext` een `DbSet` toe voor jouw verzameling:

   ```csharp
   public DbSet<Pokemon> Pokemons { get; set; }
   ```

6. Maak een migratie aan. Zie de theorie van week 3 (§3.6) voor uitgebreide instructies:

   ```powershell
   Add-Migration "My First Migration"
   ```

7. Werk je database bij en controleer in phpMyAdmin dat de database en de tabel zijn aangemaakt:

   ```powershell
   Update-Database
   ```

8. Maak in `Program.cs` een nieuwe context aan:

   ```csharp
   MyAppDataContext dataContext = new MyAppDataContext();
   ```

9. Maak een nieuw object van jouw class en geef een waarde op voor alle properties:

   ```csharp
   Pokemon pikachu = new Pokemon();
   pikachu.Name = "Pikachu";
   pikachu.Ability = "Static";
   ```

10. Voeg je object toe aan de context:

    ```csharp
    dataContext.Pokemons.Add(pikachu);
    ```

11. Sla de wijzigingen op:

    ```csharp
    dataContext.SaveChanges();
    ```

12. Controleer in phpMyAdmin dat je object in de tabel staat.
