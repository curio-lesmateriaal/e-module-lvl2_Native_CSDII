difficulty: 2
title: Eerste rij toevoegen
type: external
description: Voeg met code één ToDo toe aan je database.
task: Voeg in je Week3.ToDo-project code toe die één <code>ToDo</code> aanmaakt, toevoegt en opslaat.
environment: Visual Studio 2022 — je project Week3.ToDo
steps:
  - Open in <code>Program.cs</code> een <code>using (var db = new ToDoContext())</code>-blok.
  - Maak een <code>ToDo</code> aan met een titel, beschrijving, deadline (<code>DateTime</code>) en <code>IsDone = false</code>.
  - Doe <code>db.ToDos.Add(taak);</code> en daarna <code>db.SaveChanges();</code>.
  - Run de app en controleer in je database dat de rij bestaat.
deliverables:
  - Screenshot van de tabel met de nieuwe rij
hint: "`new DateTime(2026, 10, 1)` is een geldige deadline."
solution: |-
  ```csharp
  using (var db = new ToDoContext())
  {
      var taak = new ToDo
      {
          Title = "Oefening 1 maken",
          Description = "Eerste rij toevoegen met EF Core",
          Deadline = new DateTime(2026, 10, 1),
          IsDone = false
      };
      db.ToDos.Add(taak);
      db.SaveChanges();
  }
  ```
