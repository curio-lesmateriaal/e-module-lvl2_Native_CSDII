id: 5
difficulty: 5
title: Menu met een while-lus
type: external
description: Breng de vier bewerkingen samen in één menu.
task: Bouw een console-menu dat blijft draaien tot de gebruiker "stoppen" kiest.
environment: Visual Studio 2022 — je project Week3.ToDo
steps:
  - Maak een <code>while (true)</code>-lus die een menu print (1 tonen, 2 toevoegen, 3 afvinken, 4 verwijderen, 5 stoppen).
  - Lees de keuze en gebruik een <code>switch</code> om de juiste methode aan te roepen.
  - Bij keuze 5 — <code>break;</code> uit de lus.
  - Open per bewerking een nieuw <code>using (var db = new ToDoContext())</code>-blok.
deliverables:
  - Program.cs met aparte methoden per bewerking
  - Screenshot van een sessie waarin je alle opties gebruikt
hint: Zet elke case in een eigen methode (`ToonAlles()`, `VoegToe()`, ...) zodat de switch kort blijft.
solution: |-
  ```csharp
  while (true)
  {
      Console.WriteLine("1) Tonen  2) Toevoegen  3) Afvinken  4) Verwijderen  5) Stoppen");
      switch (Console.ReadLine())
      {
          case "1": ToonAlles(); break;
          case "2": VoegToe(); break;
          case "3": Afvinken(); break;
          case "4": Verwijderen(); break;
          case "5": return;
          default: Console.WriteLine("Onbekende keuze."); break;
      }
  }
  ```
