difficulty: 6
title: Seed-data en één roundtrip
type: external
description: Vul de database met beginwaarden en bekijk het batchgedrag.
task: Schrijf een methode die de database vult met vijf standaardtaken als de tabel nog leeg is.
environment: Visual Studio 2022 — je project Week3.ToDo
steps:
  - Controleer met <code>db.ToDos.Any()</code> of er al taken zijn.
  - Zo niet — maak vijf <code>ToDo</code>-objecten en voeg ze toe met <code>db.ToDos.AddRange(...)</code>.
  - Roep één keer <code>db.SaveChanges()</code> aan.
  - Lees in de theorie na wat er gebeurt met roundtrips en batching bij meerdere INSERT's.
deliverables:
  - De seed-methode
  - Twee tot drie zinnen — waarom is één SaveChanges met vijf toevoegingen efficiënter dan vijf keer SaveChanges?
hint: EF bundelt de INSERT's die tussen twee SaveChanges-aanroepen ontstaan in zo min mogelijk roundtrips.
solution: |-
  ```csharp
  if (!db.ToDos.Any())
  {
      db.ToDos.AddRange(
          new ToDo { Title = "Inloggen bij Itslearning", Deadline = DateTime.Now.AddDays(1) },
          new ToDo { Title = "Theorie week 4 lezen", Deadline = DateTime.Now.AddDays(2) },
          new ToDo { Title = "Oefeningen maken", Deadline = DateTime.Now.AddDays(3) },
          new ToDo { Title = "Inleveropdracht starten", Deadline = DateTime.Now.AddDays(5) },
          new ToDo { Title = "Inleveren via Itslearning", Deadline = DateTime.Now.AddDays(7) });
      db.SaveChanges();
  }
  ```
