In deze opdracht verbind je een **bestaande** app met je lokale database. Het startproject **`BoekenOnline.zip`** staat op **Itslearning**.

## Stappen

1. Download `BoekenOnline.zip` van Itslearning, pak het uit en open het project.
2. Klik met de rechtermuisknop op **Solution 'BoekenOnline'** in de Solution Explorer en kies **Restore NuGet Packages**.
3. Start **Laragon** (of andere databasesoftware).
4. Pas in `BoekenOnlineContext.cs` de gegevens aan naar die van jouw database (waarschijnlijk alleen gebruikersnaam en wachtwoord).
5. Maak je eerste migratie aan. Ga naar **Tools → NuGet Package Manager → Package Manager Console** en typ:

   ```powershell
   Add-Migration "My First Migration"
   ```

   Krijg je een foutmelding? Vraag om hulp. Anders ga je door naar de volgende stap.
6. Werk je database bij:

   ```powershell
   Update-Database
   ```

   Ook hier: bij een foutmelding, vraag om hulp.
7. Bekijk je database in phpMyAdmin. Als het goed is zie je een database `csd_iv_boekenOnline_v_1_0`. Open die en bekijk de tabellen. Bekijk vooral de tabel `Books` en vergelijk die met de class `Book` in C#.
8. Start je app. Kijk als het hoofdmenu verschijnt opnieuw in de tabel `Books`: er zijn nu 10 boeken ingevoegd (vraag om hulp als dat niet zo is).
9. Kijk rond in de app: wat kun je allemaal, welke boeken staan erin, enzovoort.
