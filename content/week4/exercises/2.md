difficulty: 3
title: Alles tonen + invoer van de gebruiker
type: external
description: Print alle taken en laat de gebruiker een nieuwe toevoegen.
task: Toon eerst alle taken uit de database en vraag daarna de gebruiker om een nieuwe taak in te voeren.
environment: Visual Studio 2022 — je project Week3.ToDo
steps:
  - Loop met een <code>foreach</code> door <code>db.ToDos</code> en print per taak de titel en of hij voldaan is.
  - Vraag met <code>Console.ReadLine()</code> een titel en beschrijving.
  - Maak een <code>ToDo</code> met die invoer, <code>Add</code> en <code>SaveChanges</code>.
  - Print een bevestiging met de ingevoerde titel.
deliverables:
  - Program.cs
  - Screenshot van een run met bestaande taken + een nieuwe toevoeging
hint: Doe het tonen en toevoegen binnen hetzelfde using-blok, of open twee blokken na elkaar.
solution: |-
  ```csharp
  using (var db = new ToDoContext())
  {
      foreach (var t in db.ToDos)
          Console.WriteLine($"{t.Title} - {(t.IsDone ? "voldaan" : "open")}");

      Console.Write("Nieuwe titel: ");
      string titel = Console.ReadLine();
      Console.Write("Beschrijving: ");
      string omschrijving = Console.ReadLine();

      db.ToDos.Add(new ToDo { Title = titel, Description = omschrijving, Deadline = DateTime.Now, IsDone = false });
      db.SaveChanges();
      Console.WriteLine($"'{titel}' toegevoegd!");
  }
  ```
