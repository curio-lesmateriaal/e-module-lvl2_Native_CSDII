title: Class Voertuig
type: external
description: Schrijf een class Voertuig met fields en een constructor.
task: Maak een class <code>Voertuig</code> met de eigenschappen kenteken, merk, type en dagprijs, plus een constructor die ze instelt.
environment: Visual Studio 2022 — je project Week1.Oefeningen
steps:
  - Voeg een nieuw bestand <code>Voertuig.cs</code> toe (rechtsklik project &rarr; Add &rarr; Class).
  - Geef de class publieke properties voor <code>Kenteken</code>, <code>Merk</code>, <code>Type</code> (string) en <code>Dagprijs</code> (decimal).
  - Schrijf een constructor die deze vier waarden als parameters krijgt en toewijst met <code>this.</code>.
  - Maak in <code>Program.cs</code> twee verschillende voertuigen aan met <code>new Voertuig(...)</code>.
  - Print van beide voertuigen het merk en de dagprijs.
deliverables:
  - Voertuig.cs
  - Screenshot van de console-output
hint: Kijk naar de constructor van de class Car uit de theorie — precies dezelfde opbouw.
solution: |-
  ```csharp
  public class Voertuig
  {
      public string Kenteken { get; set; }
      public string Merk { get; set; }
      public string Type { get; set; }
      public decimal Dagprijs { get; set; }

      public Voertuig(string kenteken, string merk, string type, decimal dagprijs)
      {
          this.Kenteken = kenteken;
          this.Merk = merk;
          this.Type = type;
          this.Dagprijs = dagprijs;
      }
  }
  ```
