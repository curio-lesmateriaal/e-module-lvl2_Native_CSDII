## Opdracht 1 – Velden aanmaken

Maak in `Game.cs` de volgende velden aan:

1. Een private integer–field `gameNumber`;
2. Een private float `gameSpeed`;
3. Een private string `levelSummary`;
4. Een private string `playerName`;
5. Een private int `numberOfPlayers`;
6. Een private int `score`.

## Opdracht 2 – Methoden aanmaken

Maak in `Game.cs` de volgende methoden aan:

1. Een public methode `SetGameNumber` die één int-parameter heeft. Stel `gameNumber` in op de waarde van de meegestuurde parameter;
2. Een public methode `GetGameNumber` die het `gameNumber` teruggeeft;
3. Een public methode `ResetGameSpeed` die de `gameSpeed` instelt op 1;
4. Een public methode `SetGameSpeed` die de `gameSpeed` instelt op de meegestuurde waarde;
5. Een public methode `GetGameSpeed` die de `gameSpeed` teruggeeft;
6. Een public methode `IsRunning` die teruggeeft of het spel 'runt' (`gameSpeed` is hoger dan 0);
7. Een public methode `DecreaseGameSpeed` die de `gameSpeed` met 10% vermindert (`gameSpeed` mag nooit lager zijn dan 0);
8. Een public methode `IncreaseGameSpeed` die de `gameSpeed` met 10% verhoogt;
9. Een public methode `SetLevelSummary` die de `levelSummary` instelt op 'We're in the end game now';
10. Een public methode `GetLevelSummary` die de `levelSummary` teruggeeft;
11. Een public methode `SetPlayerName` die de `playerName` instelt op de meegestuurde string;
12. Een public methode `GetPlayerName` die de `playerName` teruggeeft;
13. Een methode `SetNumberOfPlayers` die `numberOfPlayers` instelt op de meegestuurde (int) waarde;
14. Een methode `GetNumberOfPlayers` die het aantal spelers teruggeeft;
15. Een methode `KillPlayer` die het aantal spelers met één vermindert; het aantal spelers mag niet lager worden dan 0;
16. Een methode `ResurrectPlayer` die het aantal spelers met één ophoogt;
17. Een methode `IncreaseScore` die de score met één ophoogt;
18. Een methode `ResetScore` die de score reset naar 0;
19. Een methode `GetScore` die de score teruggeeft.

## Opdracht 3 – Constructors

Neem de theorie over constructors nog eens goed door. Schrijf vervolgens drie constructors in `Game.cs`:

1. Eén zonder parameters. Stel de `gameSpeed` in op 10;
2. Eén met de juiste parameters, die de volgende velden instelt:
   1. `gameNumber` op de waarde van de meegegeven parameter
   2. `gameSpeed` op de waarde van de meegegeven parameter
   3. `levelSummary` op de waarde van de meegegeven parameter
   4. `playerName` op de waarde van de meegegeven parameter
   5. `numberOfPlayers` op de waarde van de meegegeven parameter
3. Eén met de juiste parameters, die de volgende velden instelt:
   1. `gameNumber` op de waarde van de meegegeven parameter
   2. `levelSummary` op de waarde van de meegegeven parameter
   3. `playerName` op de waarde van de meegegeven parameter
   4. `numberOfPlayers` op 6
   5. `gameSpeed` op 3

## Opdracht 4 – Overloaded methods

Maak in `Game.cs` de volgende (overloaded) methodes aan:

1. Een public methode `IncreaseGameSpeed` die de `gameSpeed` verhoogt met de opgegeven waarde;
2. Een public methode `DecreaseGameSpeed` die de `gameSpeed` verlaagt met de opgegeven waarde;
3. Een methode `KillPlayer` die het aantal spelers met het opgegeven aantal verlaagt; het aantal spelers mag niet lager worden dan 0;
4. Een methode `ResurrectPlayer` die het aantal spelers met het opgegeven aantal verhoogt;
5. Een methode `IncreaseScore` die de score verhoogt met de meegegeven parameter;
6. Een methode `SetLevelSummary` die de `levelSummary` instelt op de meegegeven waarde.

<x-callout type="tip">

Dit zijn **overloaded methods**: methoden met dezelfde naam als een methode die je al had (uit opdracht 2), maar met een andere parameterlijst. C# kiest bij het aanroepen automatisch de juiste versie op basis van de meegegeven argumenten.

</x-callout>

## Opdracht 5 – Methoden aanroepen

In `Helper.cs` staan een aantal methoden die nog geen code hebben. Zorg ervoor dat iedere methode doet wat hij moet doen. Gebruik hiervoor de methoden die je zojuist in `Game.cs` hebt gemaakt; een referentie naar het game-object zit in het veld `game`.

1. `AddFivePlayers`: voegt 5 nieuwe spelers toe aan de game;
2. `KillTwoPlayers`: vermindert het aantal spelers in de game met 2;
3. `SetScoreToFive`: stelt de score in op 5;
4. `NewGame`: start een hele nieuwe game;
5. `PauseGame`: stelt de `gameSpeed` in op 0;
6. `ResumeGame`: stelt de `gameSpeed` in op 1;
7. `EndGame`: stelt het aantal spelers in op 3, de score op 42 en de `gameSpeed` op 0;
8. `SetPlayerNameToNorbert`: stelt de `playerName` in op "Norbert";
9. `SetGameNumberToThree`: stelt de `gameNumber` in op 3;
10. `SetLevelSummaryToReadyPlayerOne`: stelt de `levelSummary` in op 'Ready Player One'.
