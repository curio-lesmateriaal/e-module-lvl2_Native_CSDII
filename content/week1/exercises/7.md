title: Refactor naar een aparte Verhuuradministratie

description: Verplaats de logica uit Program.cs naar een eigen class.
task: Maak een class <code>Verhuuradministratie</code> die de lijst met verhuringen beheert, en houd <code>Program.cs</code> zo kort mogelijk.
environment: Visual Studio 2022 — je project Week1.Oefeningen
steps:
  - Maak <code>Verhuuradministratie</code> met een privé <code>List&lt;Verhuur&gt;</code>.
  - Voeg methoden toe — <code>VoegToe(Verhuur verhuur)</code>, <code>ToonOverzicht()</code> en <code>decimal BerekenOmzet()</code>.
  - Laat <code>Program.cs</code> alleen nog objecten aanmaken en methoden van de administratie aanroepen.
  - Controleer dat de output identiek is aan oefening 6.
deliverables:
  - Verhuuradministratie.cs en de afgeslankte Program.cs
  - Korte uitleg (2-3 zinnen) waarom deze opzet overzichtelijker is
hint: Dit heet "scheiding van verantwoordelijkheden" — Program.cs stuurt aan, de administratie-class weet hóe het werkt.
solution: |-
  ```csharp
  public class Verhuuradministratie
  {
      private List<Verhuur> verhuringen = new();

      public void VoegToe(Verhuur verhuur) => verhuringen.Add(verhuur);

      public void ToonOverzicht()
      {
          foreach (Verhuur v in verhuringen) v.ToonBon();
      }

      public decimal BerekenOmzet()
      {
          decimal omzet = 0;
          foreach (Verhuur v in verhuringen)
              omzet += v.Voertuig.BerekenPrijs(v.AantalDagen);
          return omzet;
      }
  }
  ```
