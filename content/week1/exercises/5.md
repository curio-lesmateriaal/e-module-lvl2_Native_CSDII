Bekijk de twee stukjes code hieronder. Schrijf voor allebei op **wat er geprint wordt** en **waarom**. Voer daarna de code uit in je project om te controleren.

## Fragment A

```csharp
int teller = 0;

void VerhoogMet(int waarde)
{
    waarde = waarde + 10;
}

VerhoogMet(teller);
Console.WriteLine(teller);
```

## Fragment B

```csharp
var voertuig = new Voertuig("AB-12-CD", "Opel", "Corsa", 40m);

void MaakDuurder(Voertuig v)
{
    v.Dagprijs = v.Dagprijs + 10;
}

MaakDuurder(voertuig);
Console.WriteLine(voertuig.Dagprijs);
```

## Tips

- Een `int` is een **value type**: de methode krijgt een kopie.
- Een class is een **reference type**: de methode werkt op hetzelfde object.
- Noteer je antwoord in het tekstbestand dat je bij de inleveropdracht toevoegt.
