title: Klant en Verhuur met referenties
type: external
description: Laat een Verhuur naar een bestaand Voertuig en een bestaande Klant verwijzen.
task: Maak classes <code>Klant</code> en <code>Verhuur</code>. Een <code>Verhuur</code> krijgt in de constructor een <code>Voertuig</code> en een <code>Klant</code> mee.
environment: Visual Studio 2022 — je project Week1.Oefeningen
steps:
  - Maak <code>Klant</code> met <code>Naam</code> en <code>Email</code> en een constructor.
  - Maak <code>Verhuur</code> met properties <code>Voertuig</code>, <code>Klant</code>, <code>AantalDagen</code>.
  - Laat de constructor van <code>Verhuur</code> ook meteen <code>Voertuig.Verhuur()</code> aanroepen.
  - Voeg aan <code>Verhuur</code> een methode <code>ToonBon()</code> toe die klantnaam, merk en totaalprijs print.
  - Maak in <code>Program.cs</code> één klant, één voertuig en één verhuur; roep <code>ToonBon()</code> aan.
deliverables:
  - Klant.cs en Verhuur.cs
  - Screenshot van de bon in de console
hint: Geef in Program.cs eerst het voertuig- en klantobject een naam, en geef die namen daarna door aan `new Verhuur(voertuig, klant, 3)` — net als RaceCar aan RaceDriver.
solution: |-
  ```csharp
  public class Verhuur
  {
      public Voertuig Voertuig { get; set; }
      public Klant Klant { get; set; }
      public int AantalDagen { get; set; }

      public Verhuur(Voertuig voertuig, Klant klant, int aantalDagen)
      {
          Voertuig = voertuig;
          Klant = klant;
          AantalDagen = aantalDagen;
          Voertuig.Verhuur();
      }

      public void ToonBon()
      {
          decimal totaal = Voertuig.BerekenPrijs(AantalDagen);
          Console.WriteLine($"Bon voor {Klant.Naam}: {Voertuig.Merk}, {AantalDagen} dagen = € {totaal}");
      }
  }
  ```
