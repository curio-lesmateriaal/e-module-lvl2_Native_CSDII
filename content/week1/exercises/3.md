title: Methoden met gedrag
type: external
description: Geef Voertuig gedrag met methoden en een privéveld.
task: Voeg aan <code>Voertuig</code> een privéveld <code>isVerhuurd</code> toe en de methoden <code>Verhuur()</code>, <code>LeverIn()</code> en <code>BerekenPrijs(int dagen)</code>.
environment: Visual Studio 2022 — je project Week1.Oefeningen
steps:
  - Voeg een <code>private bool isVerhuurd;</code> toe en zet die in de constructor op <code>false</code>.
  - <code>Verhuur()</code> zet <code>isVerhuurd</code> op true, maar print een waarschuwing als het voertuig al verhuurd is.
  - <code>LeverIn()</code> zet <code>isVerhuurd</code> weer op false.
  - <code>BerekenPrijs(int dagen)</code> geeft <code>Dagprijs * dagen</code> terug.
  - Test alle methoden vanuit <code>Program.cs</code>, ook het geval "al verhuurd".
deliverables:
  - Bijgewerkte Voertuig.cs
  - Screenshot waarin de "al verhuurd"-waarschuwing te zien is
hint: Gebruik een `if (isVerhuurd) { ... } else { ... }` in `Verhuur()`, net als `Accelerate()` in de theorie.
solution: |-
  ```csharp
  private bool isVerhuurd;

  public void Verhuur()
  {
      if (isVerhuurd)
      {
          Console.WriteLine($"{Merk} met kenteken {Kenteken} is al verhuurd!");
      }
      else
      {
          isVerhuurd = true;
          Console.WriteLine($"{Merk} is nu verhuurd.");
      }
  }

  public void LeverIn() => isVerhuurd = false;

  public decimal BerekenPrijs(int dagen) => Dagprijs * dagen;
  ```
