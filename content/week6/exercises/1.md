Bekijk dit JSON-antwoord van een fictieve API:

```json
{
  "id": 7,
  "kenteken": "AB-123-C",
  "merk": "Volkswagen",
  "beschikbaar": true,
  "kleuren": ["blauw", "zwart"],
  "eigenaar": {
    "naam": "De Sleutel",
    "plaats": "Breda"
  }
}
```

**Vragen (noteer je antwoorden):**

1. Hoeveel eigenschappen heeft het buitenste object?
2. Welk C#-type past bij `id`, bij `beschikbaar` en bij `kleuren`?
3. Waarom heb je voor `eigenaar` een aparte class nodig?
4. Schrijf de twee C#-classes op die bij deze JSON passen.
