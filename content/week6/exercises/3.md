difficulty: 4
title: Deserialiseren naar een object
type: external
description: Zet de ditto-JSON om naar een Pokemon-object.
task: Maak een class <code>Pokemon</code> en deserialiseer de JSON van oefening 2 ernaartoe.
environment: Visual Studio 2022 — je project Week6.Api
steps:
  - Voeg een class <code>Pokemon</code> toe met properties <code>Id</code> (int), <code>Name</code> (string), <code>Weight</code> (int).
  - Voeg <code>using System.Text.Json;</code> toe.
  - Maak <code>JsonSerializerOptions</code> met <code>PropertyNameCaseInsensitive = true</code>.
  - Doe <code>var pokemon = JsonSerializer.Deserialize&lt;Pokemon&gt;(content, options);</code>.
  - Print <code>pokemon.Id</code>, <code>pokemon.Name</code> en <code>pokemon.Weight</code>.
deliverables:
  - Program.cs en Pokemon.cs
  - Screenshot met de drie waarden
hint: In de JSON staat "id" met een kleine letter — zonder PropertyNameCaseInsensitive blijft Id op 0 staan.
solution: |-
  ```csharp
  var options = new JsonSerializerOptions { PropertyNameCaseInsensitive = true };
  var pokemon = JsonSerializer.Deserialize<Pokemon>(content, options);
  Console.WriteLine($"{pokemon.Id} - {pokemon.Name} - {pokemon.Weight}");
  ```
