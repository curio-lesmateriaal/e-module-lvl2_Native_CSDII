difficulty: 3
title: Eerste API-aanroep
type: external
description: Roep PokéAPI aan en print de ruwe JSON.
task: Maak een console-app die de JSON van <code>https://pokeapi.co/api/v2/pokemon/ditto</code> ophaalt en in de console print.
environment: Visual Studio 2022 — nieuw Console App-project Week6.Api
steps:
  - Maak <code>Main</code> asynchroon — <code>static async Task Main(string[] args)</code>.
  - Maak een <code>HttpClient</code> aan.
  - Doe <code>await client.GetAsync(...)</code> en lees het antwoord met <code>await response.Content.ReadAsStringAsync()</code>.
  - Print de string.
deliverables:
  - Program.cs
  - Screenshot van (een deel van) de JSON in de console
hint: Krijg je een foutmelding dat await niet mag? Dan is je Main nog niet async.
solution: |-
  ```csharp
  static async Task Main(string[] args)
  {
      var client = new HttpClient();
      var response = await client.GetAsync("https://pokeapi.co/api/v2/pokemon/ditto");
      var content = await response.Content.ReadAsStringAsync();
      Console.WriteLine(content);
  }
  ```
