difficulty: 5
title: JSON teruggeven
type: external
description: Serialiseer een lijst objecten naar JSON en stuur die als antwoord.
task: Maak een route <code>/voertuigen</code> die een hardcoded <code>List&lt;Voertuig&gt;</code> als JSON teruggeeft.
environment: Visual Studio 2022 — je project Week6.Server
steps:
  - Maak een class <code>Voertuig</code> met <code>Id</code>, <code>Kenteken</code>, <code>Merk</code>.
  - Maak in code een lijst met 3 voertuigen.
  - Bij route <code>/voertuigen</code> — <code>string json = JsonSerializer.Serialize(lijst);</code>.
  - Zet <code>context.Response.ContentType = "application/json";</code> en stuur de JSON.
  - Controleer het resultaat in de browser (broncode) of in Thunder Client.
deliverables:
  - Program.cs en Voertuig.cs
  - Screenshot van de JSON-uitvoer
hint: "`JsonSerializer.Serialize` doet precies het omgekeerde van `Deserialize` uit week 5."
solution: |-
  ```csharp
  if (pad == "/voertuigen")
  {
      string json = JsonSerializer.Serialize(voertuigen);
      context.Response.ContentType = "application/json";
      byte[] buffer = Encoding.UTF8.GetBytes(json);
      context.Response.ContentLength64 = buffer.Length;
      context.Response.OutputStream.Write(buffer, 0, buffer.Length);
      context.Response.OutputStream.Close();
  }
  ```
